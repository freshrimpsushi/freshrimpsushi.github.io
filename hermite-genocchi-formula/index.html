에르미트-제노키 공식

1031 수치해석  작성일: 0001-01-01 
작성자: 류대식 사장  

목차

서로 다른 $x_{0}, \cdots , x_{n}$ 에 대해 $f \in C^{n} \left( \mathscr{H} \left\{ x_{0}, \cdots , x_{n} \right\} \right) $ 이라고 하자. 그러면 $\displaystyle \tau_{n} := \left\{ ( t_{1} , \cdots , t_{n} ) : t_{i} \ge 0 \land \sum_{i=1}^{t} t_{i} \le 1 \right\}$ 과 $\displaystyle t_{0} = 1 - \sum_{i=1}^{n} t_{i}$ 에 대해 $\displaystyle f [ x_{0}, \cdots , x_{n} ] = \int \cdots \int_{\tau_{n}} f^{(n)} ( t_{0} x_{0} + \cdots + t_{n} x_{n} ) dt_{1} \cdots dt_{n}$* $\mathscr{H} \left\{ a,b,c, \cdots \right\} $ 는 $a,b,c, \cdots$ 를 포함하는 가장 작은 구간을 나타낸다.에르미트-제노키 공식은 그 자체가 복잡한 수식으로 서술되는 것과 달리 계차상을 더 자유롭게 쓸 수 있도록 일반화해준다. 어떻게 보면 오히려 에르미트-제노키 공식을 통해 새로이 정의되는 계차상이 진짜고, 기존의 계차상이 이 새로운 계차상을 이해하기 쉽도록 표현한 것이라고 할 수도 있다.만약 $f [ \underbrace{  x_{i} , \cdots , x_{i} }_{ n+1 } ]$ 이라는 계차상이 존재할 수 있다면 $\displaystyle \sum_{i=0}^{n} t_{i} = 1$ 이므로 $t_{0} x_{0} + \cdots + t_{n} x_{n} = t_{0} x_{i} + \cdots + t_{n} x_{i} = x_{i}$ 이고, $f^{(n)} ( x_{i} )$ 는 상수취급되어 적분 밖으로 나와서 $$ \displaystyle f [ \underbrace{  x_{i} , \cdots , x_{i} }_{ n+1 } ] = f^{(n)} ( x_{i} ) \int \cdots \int_{\tau_{n}} 1 dt_{1} \cdots dt_{n} $$ 한편 적분범위 $\tau_{n}$ 을 $3$차원까지 나타내보면 위 그림과 같은 구역을 나타낸다. 이들의 볼륨 $\displaystyle \int \cdots \int_{\tau_{n}} 1 dt_{1} \cdots dt_{n}$ 는 간단하게도 $\displaystyle \text{vol} ( \tau_{n} ) =  {{1} \over {n!}}$ 와 같이 계산되므로 $$ \displaystyle f [ \underbrace{  x_{i} , \cdots , x_{i} }_{ n+1 } ] = {{1} \over {n!}} f^{(n)} ( x_{i} ) $$ 이는 $x_{0}, \cdots , x_{n}$ 가 모두 같은 경우인데, 원래 계차상의 정의 $\displaystyle f [ x_{0} , \cdots , x_{n} ] : = {{ f [ x_{1} , \cdots , x_{n} ]  - f [ x_{0} , x_{n-1} ] } \over { x_{n} - x_{0} }}$ 에 따르면 분모가 $0$ 이 되어 버려서 사실 있을 수 없는 계산이다. 그러나 에르미트-제노키 공식은 수식적으로 그딴 건 신경쓰지 않으며, 다음과 같은 따름정리를 갖는다.**[3]'** $\displaystyle f [ x_{i} , x_{i} ] = f' ( x_{i} )$**[4]'** $\displaystyle f [ \underbrace{  x_{i} , \cdots , x_{i} }_{ n+1 } ] = {{1} \over {n!}} f^{(n)} ( x_{i} ) $또한 이제와서 보면 딱히 다 같을 이유도 없기는 하다. 계차상을 쓰는 이유는 수식적으로 미분계수를 구하기 어려워서 쓰는건데, 이왕 미분계수에 대한 정보가 있다면 최대한 활용하는 게 낫다. 예로써 $\displaystyle f[x_{0}, x_{1}, x_{1}] = {{ {{ f(x_{1}) - f(x_{1}) } \over { x_{1} - x_{1} }}  - f [ x_{1} , x_{0} ] } \over { x_{1} - x_{0} }}$ 과 같은 모양이 있다고 생각해보자. 물론 이 식은 수학적으로 말이 안 되지만, 개념적으로는 $\displaystyle {{ f(x_{1}) - f(x_{1}) } \over { x_{1} - x_{1} }} \equiv \lim_{h \to 0} {{ f(x_{1} + h) - f(x_{1}) } \over { ( x_{1} + h ) - x_{1} }} = f'(x_{1}) $ 과 같은 주장이 그렇게 허무맹랑하지만은 않다. 다음과 같이 미분계수가 있으면 있는대로, 없으면 없는대로 쓰는 것이다. $$ \displaystyle f[x_{0}, x_{1}, x_{1}] = {{ f'(x_{1})  - f [ x_{1} , x_{0} ] } \over { x_{1} - x_{0} }} $$ 노드의 중복을 허용한 일반화는 여기서 멈추지 않고 미분에 대한 가능성까지 열어준다. 가령 $f[x_{0} , x_{1}, x]$ 와 같이 아직 픽스되지 않은 변수 $x$ 가 있을 때, 이 계차상을 $x$ 에 대해 미분하면 $$ \displaystyle {{ d } \over { dx }} f[x_{0} , x_{1}, x] = \lim_{h \to \infty} {{ f[x_{0} , x_{1}, x+h] - f[x_{0} , x_{1}, x] } \over { h }} $$ 계차상은 노드의 순서에 상관없이 항상 같으므로 $$ \displaystyle {{ d } \over { dx }} f[x_{0} , x_{1}, x] = \lim_{h \to \infty} {{ f[x_{0} , x_{1}, x+h] - f[ x, x_{0} , x_{1}] } \over { (x+h) - x }} $$ 계차상의 정의에 의해 $$ \displaystyle {{ d } \over { dx }} f[x_{0} , x_{1}, x] = \lim_{h \to \infty} f[x, x_{0} , x_{1}, x+h] = f[x, x_{0} , x_{1}, x] $$ 이를 $x_{0}, \cdots , x_{n}$ 에 대해 일반화하면 $f'[x_{0}, \cdots , x_{n}, x] = f[x, x_{0}, \cdots , x_{n}, x]$ 인데, 계차상을 $x$ 에 대해 미분하면 $x$ 가 하나 더 늘어난다고 요약할 수 있다. 이러한 사실은 계차상에 들어가는 노드가 많을수록 미분을 많이 취한 것으로 볼 수 있다는 점에서 직관과 잘 맞아 떨어진다.한편 유도 자체는 수학적 귀납법으로 어렵지 않게 할 수 있으나, 그냥 수식이 길고 인덱스를 사용함에 있어서 더러운 부분이 많다. 그냥 팩트로써 받아들이고 넘어가는 것을 추천한다.
